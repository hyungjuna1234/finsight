# PRD: FinSight

## 목표
카드 이용내역 파일만 올리면, 연동 없이 한 달 지출을 정리해 보여준다.
포지셔닝: "연동 없이 카드 내역 파일만. 원본은 90일 후 자동 삭제, 언제든 전부 삭제."

## 사용자
한국 개인 사용자(한국어 UI, KRW).
| 페르소나 | 목표 | 결제 이유 | 이탈 이유 |
|---|---|---|---|
| 지민(26, 사회초년생) | 월급이 어디로 새는지 | 절약 포인트 리포트 | 모바일에서 파일을 못 받음 |
| 현우(34, 카드 4장) | 카드 여러 장을 한 화면에서 | 추이, 채팅 | 카드마다 업로드가 번거로움 |
| 수아(29, 구독 과다) | 구독 총액과 해지 후보 | 정기결제 목록 | 탐지 누락 |
| 태호(38, 가계부 앱 이탈) | 연동 없이 분석만 | 파일 방식, 확실한 삭제 | 분류 오류 |

Aha moment: 업로드 후 1분 안에 총지출, 1위 카테고리, TOP5 가맹점을 보는 순간.

## 핵심 기능
1. **업로드**: 카드 이용내역(CSV·xls·xlsx, 10MB·1만 행 이하). 여러 파일은 하나씩 차례로. Claude가 열을 매핑하고 코드가 파싱. 같은 카드사 형식은 다음부터 확인 없이 저장.
2. **분류와 대시보드(Free)**: 15개 카테고리 자동 분류, 사용자 수정(이번 건만 / 같은 가맹점 모두). 원하는 월 하나씩: 총지출, 카테고리 차트, TOP5, 거래 목록.
3. **Pro(₩6,900/월, 기본 통화 $4.99)**: AI 인사이트 리포트(숫자는 서버 집계, 문장은 AI), 가벼운 Q&A 채팅(세션 보관, 도구 2개), 여러 달 추이·전월 비교, 정기결제 목록.
4. **전환 장치**: `/demo` 샘플 대시보드(로그인 없음), Free 화면 안의 Pro 티저(정기결제 합계, 전월 비교 잠금, 흐리게 처리한 추이), 첫 AI 리포트 1회 무료.
5. **계정·데이터**: 카카오·구글 로그인, 필수 동의 4개 개별 체크, 업로드 삭제, 전체 데이터 삭제, 탈퇴.

남용 방지(요금제 제한 아님): 하루 업로드 30개, AI 매핑 30회, 인사이트 10회, 채팅 30회.

## MVP 제외 사항
- 은행 거래내역(이체·카드대금 감지 포함), 카드 청구서 형식
- 이메일 리마인더(대신 대시보드 "이번 달 내역을 올릴 차례예요" 배너)
- 채팅 기록 저장, 스트리밍 응답
- 전역(사용자 간) 캐시, 비동기 작업 큐
- 마이데이터·계좌 연동, PDF·이미지 명세서, 가계 공유, 투자·세무 조언
